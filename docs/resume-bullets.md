# Resume Bullets

## Full Version

- Built an enterprise LLM routing and evaluation platform with Next.js, TypeScript, PostgreSQL, Prisma, and OpenAI APIs to select models by quality, latency, token cost, context needs, task type, team budget, and policy constraints.
- Implemented mock and live eval modes, persisted run history, LLM-as-judge rubric scoring, prompt dataset management, policy audit logs, and reproducible quality/cost savings reports.

## Short Version

- Built a full-stack AI model router and eval platform that benchmarks LLMs, applies enterprise usage policy, and estimates cost savings across model choices.

## Interview Pitch

Companies adopting AI coding tools need a control plane between developers and expensive models. This project simulates that layer: it evaluates model quality, routes requests based on complexity and budget, blocks personal or unsafe usage, and generates savings reports that platform teams can use to justify routing decisions.
